# XXD Panel 348｜图鉴墨点

上半保留原照，下半把主体请进一本老博物图鉴：转成最好认的侧面标本姿态，全部用同一种深墨一点一点点出来，暗处密得几乎连成一片，亮处只剩一排单行的点勾出边缘，画面里没有一条连续的实线；身边那样东西只用几段断续的点线带过，底是一整块从照片里调淡的浅色，配一行一本正经的图鉴条目。

## 适用场景与解决的问题

适合有一个清楚主体、而且这个主体有一个好认侧影的照片：一头犀牛、一只乌龟、一只停在树枝上的鸟、一辆老自行车、一颗松果。也适合构图差、背景乱、主体小的野外照片——下半会删掉环境、把主体转成最好认的侧面标本姿态、只留它脚下或身边的一样东西，把它救成一页成立的图鉴插图。照片本身是场景时，只取最有代表性的一个单体或片段来画。

关键是全部由同一种深墨点出来：暗处密密实实，过渡处渐渐变稀，受光面留空、只在边上排一行细点，画面里没有一条连续的实线；点大小几乎一样、排列带手工的不匀，不排成格子；底是一整块从照片最有辨识度的颜色调淡而来的浅色，除墨色外没有第二种颜色。文字照图鉴的样子：左上一个小条目编号和两种语言的俗名，底部一行字距略开的斜体衬线拉丁式学名加一个类别词。避免完整场景复刻、墨点连成描边、灰色涂抹或平涂块面、点排成整齐格子、出现第二种颜色、写实彩色插画、点又稀又匀让形体发虚，以及文字挤到主体身上。

## 使用窍门

- **先给一张清楚的照片：** 先选一张主体、动作和关系都容易辨认的图，再决定输出方式与比例。
- **一句话串起参数：** 直接说“上下对照 / 左右对照 / 纯设计 + 16:9 / 3:4 / 手机壁纸”，也可以补充电脑、平板或电子手表尺寸。
- **把必须保留的内容说清楚：** 指定人物、物件、动作、关系和文字；避免同时规定过多布局细节，让风格有空间完成设计。
- **文字有三种选择：** 让模型按图片智能生成、用 `--text exact --copy` 锁定逐字文案，或用 `--text none` 完全不要文字。
- **说明现实区与设计区：** 上下或左右对照时，注明哪一侧保留照片、哪一侧负责设计转译；纯设计和壁纸则说明整张画布都要重新设计。
- **先单张试，再批量做：** 先用一张图确认模式、比例、文字和语言，再把同一套参数用于目录批处理；每轮只改一个变量，结果更容易比较。

## 开始使用

从 GitHub 安装：

```bash
npx skills add https://github.com/nevertoday/xxd-panel-348 --skill xxd-panel-348
```

安装后重新启动 Agent 会话，然后调用 `$xxd-panel-348`。也可以按需追加 `--global --agent codex --yes` 做用户级安装。

常用调用示例：

```text
/xxd-panel-348 photo.jpg --mode top-bottom --size 3:4 --text prompt --locale zh-CN
/xxd-panel-348 photo.jpg --mode left-right --size 16:9 --text prompt --locale en-US
/xxd-panel-348 photo.jpg --mode design-only --size 9:16 --text none --prefs off
/xxd-panel-348 ./photos --mode design-only --size auto,3:4 --text prompt --locale ja-JP
```

完整运行契约见 [SKILL.md](SKILL.md)；运行适配器见 [英文](references/xxd-panel-348-prompt.en.md) 与 [中文](references/xxd-panel-348-prompt.zh-CN.md)。

## 快速判断：Panel 348 适合你吗？

既要保留源图身份，也要重新构图；既要材质特征，也要主动留白。可选准确文字、智能文案或无文字；支持单图、递归目录批量以及下方四种交付模式。

## 四种输出模式

- `top-bottom`：整张画布只有上下两个全宽区域，现实照片在上、设计在下，严格各占 50%。
- `left-right`：整张画布只有左右两个全高区域，现实照片在左、设计在右，严格各占 50%，不会旋转成上下结构。
- `design-only`：整张画布只呈现 Panel 348 的设计转译，照片只作为不可见参考。
- `wallpaper-pack`：按手机、iPad、桌面和手表分别生成完整设计壁纸，可选 `linked` 连贯套装或 `independent` 四张独立。

支持多选模式与比例（`1:1`、`3:4`、`4:3`、`4:5`、`5:4`、`2:3`、`3:2`、`9:16`、`16:9`、`21:9`、`5:7`、`7:5` 或准确像素），以及模型生成文字、准确文字和无文字。传入目录会递归扫描图片，每张源图独立处理，共用一次交付设置；最终 PNG 平铺放入一个新任务目录。
